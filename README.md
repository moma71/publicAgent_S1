## 🧐 작품 소개 (Synopsis)

**핵심 갈등:**  
청담구(부촌) 출신 엘리트 공무원 강민준이 구산구(낙후)로 좌천당한 후, AI를 활용해 구산구를 전국 1등 혁신 사례로 만들며 복수하는 역전 드라마.

**메시지:**  
AI는 사람을 대체하는 것이 아니라, 사람이 더 중요한 일을 할 수 있게 돕는 도구다.

### ✨ 핵심 포인트
1. **리얼리즘**: 실제 공무원 사회의 디테일과 갈등
2. **AI 실용주의**: 뜬구름 잡는 기술이 아닌, 실제 업무에 바로 쓰는 튜토리얼 (프롬프트, RAG, 엑셀 분석)
3. **성장 서사**: 오만한 엘리트가 진정한 공공의 가치를 깨닫는 과정
4. **계층 역전**: 가장 낙후된 곳에서 가장 뒤처진 기술(AI 없음)로 가장 앞선 성과를 낸다.

<br>

## 👥 캐릭터 프로필 (Tier 1)

### 강민준 (29세, 주인공)
- **직급**: 8급 주무관 (청담구 → 구산구 좌천)
- **성격**: 서울대 행정학과 출신 엘리트, 효율성과 데이터 집착.
- **성장**: "낙후 지역 = 패배자"라는 편견을 깨고, 진정한 공무원으로서의 가치 발견.

### 박소희 (42세, 멘토)
- **직급**: 6급 과장 (복지정책과)
- **성격**: 현장 경험의 화신. 따뜻하지만 단호함.
- **Role**: 민준의 AI 접근 방식에 회의적이었으나, 점차 든든한 조력자로 변화. "서류로는 사람 못 살려요."

### 최태양 (54세, 국장)
- **직급**: 4급 기획조정국장
- **성격**: 변화를 두려워하는 "원래 그래왔어" 마인드.
- **Role**: 초반의 방해자이자 가장 큰 벽. 하지만 성과 앞에서는 확실하게 지원하는 현실적 리더.
