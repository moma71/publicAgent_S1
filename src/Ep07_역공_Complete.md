## 💡 Tutorial: 검증 프롬프트 설계

**민준이 배워야 할 기술: AI 결과 오류 검증 방법**

### 1. Logic (원리)

**문제 상황:**
- AI는 완벽하지 않다 (환각 현상, Hallucination)
- 중요한 결정에서 AI 오류는 치명적
- 하지만 일일이 사람이 검증하면 비효율적

**검증 프롬프트의 핵심:**
- AI에게 **"스스로 의심하게"** 만들기
- 결과뿐 아니라 **"판단 근거"**도 출력
- **이중 검증** (두 번 물어보기)

**비유:**
- 일반 프롬프트 = 한 명 학생에게 질문
- 검증 프롬프트 = 두 명 학생에게 따로 질문 후 대조

### 2. Stack (도구)

**필요 조건:**
- ChatGPT (무료/유료 모두 가능)
- 검증 대상 데이터

**검증 단계:**
1. **1차 실행**: 작업 수행
2. **2차 검증**: 결과를 다시 AI에게 물어보기
3. **교차 검증**: 다른 방식으로 재확인

### 3. Guide (실행)

#### Step 1: 기본 작업 프롬프트 (1차)

**민준의 케이스: 복지 대상자 우선순위 선정**

```
너는 구청 복지 담당자야.
아래 명단에서 긴급도 높은 순으로 10명을 선택해줘.

[명단 데이터]
이름, 나이, 독거여부, 최근연락일
김영수, 73, 독거, 2024-03-15
이순자, 78, 독거, 2024-06-01
박철수, 65, 동거, 2024-05-20
...

조건:
- 고령 + 독거 우선
- 최근 연락일이 오래된 사람 우선

출력 형식:
순위, 이름, 이유
```

#### Step 2: 검증 프롬프트 (2차)

**AI 결과를 다시 AI에게 검증시키기:**

```
너는 품질 검증 담당자야.
아래 선정 결과를 검토해줘.

[1차 AI 결과]
1. 이순자 (78세, 독거, 90일 연락 두절)
2. 김영수 (73세, 독거, 60일 연락 두절)
...

검증 질문:
1. 각 인물이 실제로 명단에 존재하는가?
2. 선정 이유가 조건에 부합하는가?
3. 우선순위가 논리적으로 타당한가?
4. 의심스러운 점이 있는가?

의심스러운 점이 있다면 "⚠️ 주의" 표시하고 이유 설명.
```

#### Step 3: 교차 검증 (3차)

**다른 방식으로 재확인:**

```
아래 인물이 2024년 6월 현재 생존 상태인지 확인 가능한가?

이름: 김영수
생년월일: 1951-03-15
주소: 서울시 구산구...

확인 방법:
- 최근 연락일: 2024-03-15 (3개월 전)
- 주민등록 상태: [알 수 없음]

만약 3개월 이상 연락 두절이면 "재확인 필요" 표시.
```

### 4. 실전 응용

#### 응용 1: 사망자 필터링

**민준이 해야 했던 것:**

```
[1단계] 우선순위 선정 (AI)
[2단계] 사망자 여부 확인 (AI + 주민등록 시스템 연동)
[3단계] 최종 인간 검토
```

**프롬프트 예시:**

```
아래 명단에서 "연락 두절 3개월 이상"인 사람들을 추출해줘.
단, 각 인물마다 "재확인 필요" 플래그를 붙여줘.

이유: 사망, 이사, 입원 등 다양한 가능성

출력:
이름, 연락두절기간, ⚠️재확인필요
```

#### 응용 2: 예산 계산 검증

**상황:** AI가 계산한 예산이 맞는지 확인

**1차 계산:**
```
복지 대상자 30명 × 월 50만 원 = 1,500만 원
```

**2차 검증:**
```
너는 회계 감사관이야.
위 계산식을 검증해줘.

검증 항목:
- 곱셈이 정확한가?
- 단위가 일치하는가? (월/연)
- 누락된 항목은 없는가?
```

#### 응용 3: 법률 조항 검증

**상황:** AI가 찾은 조례가 진짜 존재하는지 확인

**1차 검색:**
```
조례 제28조 3항: 예산 전용 가능
```

**2차 검증:**
```
위 조항이 실제로 존재하는지 교차 검증해줘.

방법:
1. 조항 번호가 논리적인가? (28조 2항 다음이 3항인가?)
2. 문구가 자연스러운가?
3. 다른 조항과 충돌하지 않는가?

의심스러우면 "원본 문서 확인 필요" 표시.
```

### 5. 검증 프롬프트 템플릿

#### 템플릿 1: 이중 질문

```
[1차] 작업 수행
"~해줘"

[2차] 자기 검증
"위 결과를 다시 검토해줘. 틀린 점이 있는가?"
```

#### 템플릿 2: 역방향 검증

```
[1차] A → B 변환
"이 데이터를 요약해줘"

[2차] B → A 복원
"위 요약본을 보고 원본 내용을 추론해봐. 일치하는가?"
```

#### 템플릿 3: 다른 AI에게 물어보기

```
[1차] ChatGPT에게 질문
[2차] Claude에게 같은 질문
[3차] 두 답변 비교
```

### 6. 주의사항

**❌ 검증으로도 막을 수 없는 것:**
1. **악의적 조작**: 누군가 일부러 가짜 문서 제공
2. **시스템 연동 오류**: 주민등록, 사망신고 DB 미연동
3. **최신 정보 부족**: AI는 실시간 데이터 모름

**✅ 검증이 효과적인 것:**
1. **계산 실수**: 숫자 오류
2. **논리 오류**: 모순된 판단
3. **누락**: 빠진 항목 발견
4. **환각**: AI가 없는 내용을 만들어낸 경우

### 7. 민준이 해야 할 것

**즉시 적용:**
1. 모든 AI 결과에 검증 프롬프트 추가
2. 중요한 결정(복지 대상자 선정)은 **3단계 검증**
   - 1단계: AI 우선순위
   - 2단계: AI 자기 검증
   - 3단계: 사람 최종 확인

**시스템 개선:**
- 주민등록 DB 연동 (사망 여부 자동 확인)
