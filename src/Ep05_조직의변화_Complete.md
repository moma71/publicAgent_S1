![구산구청 민원실 - 아침 민원 대기 줄](placeholder)

월요일 아침 9시. 구산구청 민원실은 이미 20명의 주민들로 가득했다. 담당 주무관 3명이 땀을 뺐다.

"어르신, 인감증명서는 2번 창구에서..."

"주차 위반 과태료는 3번 창구..."

복도 끝, 김철수가 민준을 불렀다.

"민준 씨, 저기 좀 봐봐."

김철수는 노트북 화면을 보여줬다. ChatGPT Canvas가 열려 있었다.

"이거 뭐야? 내가 쓴 보고서를 AI가 고쳐주네?"

화면에는 김철수가 작성한 '지역 상권 활성화 보고서' 초안이 있었다. 그리고 오른쪽에는 ChatGPT가 제안한 수정안이 실시간으로 나타나고 있었다.

```
[원본] 지역 상권이 어렵습니다. 대책이 필요합니다.
[수정안] 구산구 지역 상권은 최근 3년간 20% 감소세를 보이고 있습니다. 공실률 증가와 유동인구 감소가 주요 원인으로 분석되며, 단계적 지원 정책이 시급합니다.
```

"민준 씨, 이거... 20년간 손으로 하던 거 10분 만에 끝났어."

민준은 웃었다.

"형, Canvas는 협업 도구예요. AI가 초안을 다듬어주고, 형이 최종 검토만 하면 돼요."

"협업... AI랑?"

"네. AI는 형의 조수예요."

**[긴급 성명]**  
"AI 도입, 공무원 일자리 위협한다"

"강 주무관, 앉으세요."

민준은 의자에 앉았다. 박소희도 옆에 앉았다.

정민수는 서류를 꺼냈다.

"민원실만 해도 주무관 10명이 하루 200건 민원 처리해요. 그런데 AI가 그걸 다 하면... 우리 10명 중 몇 명이 잘리겠어요?"

"위원장님, AI는 사람을 자르려고 도입하는 게 아닙니다."

"위원장님, 공무원은 민간하고 달라요. 우리는 법으로 정원이 보장돼 있어요."

## 💡 Tutorial: ChatGPT Canvas 활용법

**민준이 사용한 기술: Canvas를 통한 문서 협업**

### 1. Logic (원리)

**기존 ChatGPT의 한계:**
- 대화창에서 답변 → 복사 → 워드에 붙여넣기 → 수정 → 다시 물어보기
- 반복 작업이 비효율적
- 버전 관리 어려움

**Canvas의 장점:**
- **실시간 협업**: 왼쪽에 작성, 오른쪽에 AI 제안
- **부분 수정**: 전체가 아닌 일부만 수정 요청 가능
- **버전 관리**: 이전 버전 자동 저장

**비유:**
- 일반 ChatGPT = 메신저로 작업 지시
- Canvas = Google Docs처럼 함께 작업

### 2. Stack (도구)

**필요 조건:**
- ChatGPT Plus (유료 버전) 또는 무료 버전 (제한적)
- 웹 브라우저 (크롬, 엣지 등)

**접속 방법:**
1. ChatGPT 실행
2. 새 채팅 시작
3. 프롬프트 입력 후 "Canvas로 열기" 버튼 클릭
   (또는 "Canvas로 이 문서를 작성해줘"라고 요청)

### 3. Guide (실행)

#### Step 1: Canvas 시작하기

**첫 시작 프롬프트:**

```
Canvas로 '구청 복지정책과 월간 보고서'를 작성해줘.

포함 내용:
- 이번 달 주요 성과 3가지
- 복지 대상자 신규 발굴 현황
- 다음 달 계획

형식: 공문서 양식
```

Canvas가 열리면:
- **왼쪽**: AI가 생성한 초안
- **오른쪽**: 편집 도구 (길이 조절, 가독성 개선, 이모지 추가 등)

#### Step 2: 부분 수정하기

**전체 수정이 아닌 특정 부분만 수정:**

1. 수정하고 싶은 문단 드래그
2. 오른쪽 편집 도구에서 "이 부분 수정" 선택
3. 요청사항 입력

**예시:**
```
드래그: "이번 달 복지 대상자 신규 발굴 20명"

수정 요청: "구체적인 수치와 함께 전월 대비 증가율을 추가해줘"

결과: "이번 달 복지 대상자 신규 발굴 20명 (전월 대비 150% 증가, 8명→20명)"
```

#### Step 3: 협업 패턴

**패턴 1: 초안 작성 → AI 다듬기**

```
1. 사용자가 대략 작성:
"이번 달 성과는 복지 대상자 20명 발굴입니다."

2. AI에게 요청:
"이 문장을 공식 보고서 스타일로 다듬어줘"

3. AI 결과:
"금월 복지정책과는 AI 기반 사각지대 발굴 시스템을 활용하여 신규 복지 대상자 20명을 발견했으며, 이는 전월 대비 150% 증가한 수치입니다."
```

**패턴 2: AI 초안 → 사용자 검토**

```
1. AI에게 초안 요청:
"회의록 초안 작성해줘"

2. AI가 생성

3. 사용자가 직접 수정:
- 참석자 이름 수정
- 결정 사항 추가
- 불필요한 부분 삭제

4. 최종 버전 완성
```

### 4. 실전 응용

#### 응용 1: 민원 응대문 대량 작성

**상황:** 비슷한 유형 민원 20건에 개별 답변 필요

```
Canvas로 주차 위반 이의제기 민원 응답 템플릿을 작성해줘.

템플릿 포함 요소:
- 인사말
- 민원인 입장 이해
- 현장 확인 절차 안내
- 담당자 연락처
- 마무리 인사

{{민원인 이름}}, {{위반 일시}}, {{위반 장소}} 변수 포함
```

#### 응용 2: 회의록 실시간 작성

**상황:** 회의 중 메모 → 회의 후 정리

```
1. 회의 중: Canvas에 메모
"예산 논의 - 김 과장 3억 요청 - 국장 승인 보류"

2. 회의 후: AI에게 정리 요청
"이 메모를 공식 회의록 형식으로 작성해줘"

3. AI 결과:
"안건 1. 예산 전용 건
- 김성호 과장(지역경제과) 3억 원 전용 요청
- 최태양 국장 검토 후 차주 회신 예정"
```

#### 응용 3: 보고서 버전 관리

**Canvas의 자동 저장 기능:**
- 수정할 때마다 이전 버전 자동 저장
- 하단 "버전 기록" 클릭 → 이전 버전 복구 가능

**활용:**
```
1. 초안 작성
2. 상사 피드백 반영
3. 최종 승인

만약 최종본에 문제 → 이전 버전으로 복구
```

### 5. Canvas vs 일반 ChatGPT

| 기능 | 일반 ChatGPT | Canvas |
|------|--------------|--------|
| 문서 작성 | 대화창에서 복사 | 실시간 편집 |
| 부분 수정 | 전체 다시 요청 | 원하는 부분만 수정 |
